## Findings

### Critical

None. Never-overwrite survived four fresh attacks against the real binary: an atom appearing between read and write, an out-of-range value, a full volume in both backup modes, and a re-run over the tool's own output. Measured additionally: **ENOSPC is safe at the backend level in both modes** — target unchanged, no `_exiftool_tmp`, no `_original` orphan, no partial file — so `space.py` is a better diagnostic and defence in depth rather than the only line holding the invariant. And **every error direction in the attribution partition is conservative**: no token was found that can move a conclusion *toward* `Geotagged`, and for the atom class `WRITE_INCOMPLETE` is unreachable because that write set has exactly one position-bearing member.

### High

- **H1** [supportability/testability] ✓ **two reviewers independently — the mutation gate counts a timed-out mutant as an unadmitted survivor, so its verdict depends on machine load and it refused on an unmodified tree.** `scripts/mutants.sh:79` extracts survivors with `awk -F': ' '/^ +gps_sync\./ { print $1 }'`, printing field 1 for every status line and never reading the status in field 2. `mutmut results` emits `: timeout` as well as `: survived`. Measured on a byte-verified tree: `mutants: 1944, not killed: 42`, then 14 `FAIL: … not in the baseline` lines for mutants whose true status is `timeout`, and **no `OK:` line — the gate refused**. Filtering on the status column reproduces the clean result exactly: `28` survivors, `OK: no survivor outside the baseline`, exit 0. The 28 are matcher 13, records 13, writer 2 — identical to the stamped candidate. Three consequences: NFR8's gate is not reproducible, so this pass's central verification claim cannot be checked by anyone; the printed `not killed: N` conflates two statuses, so every figure derived from it is wrong in general; and `--propose` builds the candidate from the same conflated list, where a timeout whose diff+func digest matches a prior entry is **admitted silently by the inheritance path**, permanently admitting a mutant whose status was never determined. That last direction is fail-open; the rest is fail-closed, which is why this is High and not Critical. *Fix: filter on the status token, and count `timeout` and `suspicious` under their own lines so a genuine infinite-loop mutant is surfaced rather than dropped. If a timeout is to count as unkilled, raise mutmut's timeout so load cannot decide the verdict.* **Required test:** feed the script a `mutmut results` text holding one `survived` and one `timeout` `gps_sync.` line; assert the survivor list holds exactly the `survived` name and the timeout is reported under its own count.

- **H2** [observability/testability] ✓ **two reviewers independently — the test named for the census property does not check it, so any undeclared rendering difference passes.** `tests/e2e/test_video_tree.py` → `test_it_is_001s_run_and_only_the_census_rows_moved` asserts variant counts, the `Planned` path set, the clip's `(Ignored, NOT_A_STILL)` and an unchanged media snapshot — nothing about *which renderer outputs* moved. Measured: adding an invented top-level key to `build_run_record` leaves **the entire suite green**, that test included. Independently, mutating the `NOT_A_STILL` label text — a real output difference of this diff, published in the registry mirror 003 reads — also leaves all three tiers green. This is the instrument pass 1 asked for, and its absence is why four undeclared keys (`space_demand`, `telemetry_read`, `run_level`, `files[].detail`) and two undeclared report lines entered during the fix pass unnoticed. Re-measured against the tree: the census declares **8 renderers, 7 moving**; there are **17 renderer functions**, **10 move** on a bare run, and 3–4 of those are undeclared. *Fix: flatten the bare-run record to its key-paths and assert the symmetric difference against a module-level constant carrying one comment per census row; assert the bare report's line set against a frozen list rather than only `row in text`.* **Required test:** re-run with an invented key and confirm it fails.

- **H3** [observability] ✓ **measured — `space_demand` renders `[]` on a write run, colliding with the pinned encoding for "nothing planned".** `src/gps_sync/orchestrator.py` → `_run` sets `space_demand=forecast if not options.write else ()`, and the gate is on `RunInfo`, which both renderers read. The enclosing class is named `TestTheSpaceForecastReachesEverySurface` and has no write-run JSON case, so pass-1 H10's machine-surface half is **half closed**. *Fix: render the forecast on the write run too (the same object already reaches the verdict), or omit the key entirely so absence is distinguishable from empty. The report staying dry-run-only is deliberate and declared.*

## Pass-1 closure

**All ten pass-1 Highs are closed, and every one is mutation-pinned.** Verified independently, with kill counts: H1 the merged conclusions (5 unit tests, plus the pre-fix silent shape now structurally unreachable — a dropped path raises `InternalConsistencyError`), H2 the spawn guard (2), H3 the per-file `OSError` refusal (3), H4 the block-shape call site (2), H5/M5 member resolution (one parametrisation per scan direction, and `any`→`all` kills both), H6 the e2e tier (4 mutations, 3 fatal at e2e itself; dropping `CENTROID` from `by_via` kills 13 e2e tests), H7 telemetry retention (a real `gc` reachability measure **with two negative controls** that prove it can fail), H8 the consumer mirror (3/3), H9 the registry column (4/4), H10 the census sites (4/4).

**H6 and H10 — the two the fix pass admitted it had not individually checked — both bite.** The "pins existing behaviour so it passes on shipped code" worry does not hold.

Of the 26 pass-1 Mediums, 24 are closed and most of them well. **M2** (legacy baseline identity) is open but contained and has a ready fix. **M24** is the one closed badly, recorded above as M2. **M25 is withdrawn as mistaken** by another reviewer: `statistics.fmean` in the integration tier is an *independent oracle* against production's `sum/len` compared at `abs=1e-9`, which is what an oracle is for, and no pin asserting only interpreter behaviour could be found. The fix pass's replacement of those pins is harmless and arguably better.

## Negative results, recorded so the next pass does not re-measure them

The Fujifilm fixture's closure claims **hold**, validated against three real archive originals under the shipped `-j -n -a -G4` invocation: key-for-key, instance-assignment and emission-order identical on everything production reads, differing only on tags outside `READ_TAGS`. §6 1180's group kills 5 integration tests when the 001 reading is reintroduced, and `exiftool -geotag` was run independently as an oracle — it discriminates the right instant at **250× the asserted tolerance** and refuses the uncovered clip for coverage rather than for a missing date. The real population confirms the fixture's class: 41 X-T5 MOVs, all brand `qt`, all carrying `DateTimeOriginal`+`OffsetTimeOriginal`, none positioned, none with a `meta` handler. The finalisation band is honest — 23.954–24.991 s across 41 real files, 0 outside.

`_resolve_members` is **total over the backend's refusal vocabulary**: a sweep of all nine members of both write sets found four wordings carrying **no conversion suffix at all**, and exiftool's own `Writer.pl` interpolates `$wgrp1:$tag` in every ConvInv-family wording — so the colon-token scan is right by construction, not by luck. The right-to-left rule is genuinely unobservable now (reversing the scan leaves 1,231 passing), as the user's decision intends. A stderr token that is a *path* cannot collide with a member name, because discovery admits only declared extensions. `create_date_count == 1` → `<= 1` is a true **equivalent** mutant, not a gap. The corpus tripwire fails rather than warns. The time dispatch is total and disjoint, verified against **199 real archive videos** with no refusal or `ToolFailure`. No arithmetically impossible requirement appears in the new tests — **the first pass in five where that check comes back clean** — with ten numeric assertions recomputed on both sides.

Then re-run `mutants-propose` and promote the freshly stamped candidate — measured safe, and it retires 107 legacy entries and the git dependency with them.

4. **M5, M6, M7** are one unit test each against `attribute()` and `matcher`, with no product change and no binary.
5. **M2 and M3** together: add `--video` to the reference run with invariants, and re-measure the four design figures (218→200, 109→96, 128→115, 46→41) or declare them derived at test time.
6. **The design text needs twelve corrections**, now including the four stale archive figures and two §6 sign errors. Recorded for `/design`, not for the coder.

**Method note.** Every High and every non-Low finding in this pass was found by running something — the gate, a mutation, the production reader over the live archive, or a diff of two JSON records. That is the sixth consecutive pass where measurement found the defects and reading did not. The two instruments this pass adds — a frozen bare-run key set and a load-independent gate — are the ones that make the next pass cheaper than this one.
